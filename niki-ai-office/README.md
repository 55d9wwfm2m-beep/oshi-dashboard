# NIKI AI OFFICE

複数のAIを、仮想オフィスで働く「AI社員」として管理するモバイルファーストのタスク管理アプリ（第1段階MVP）。

外部AI APIやGitHub APIには接続せず、**モックデータ + localStorage** で動作します。

## 技術構成

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS 3
- モバイルファースト / iPhone Safari 最優先
- 外部依存なし（データはブラウザの localStorage に保存）

## 開発

```bash
cd niki-ai-office
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

## 画面

| 画面 | パス | 内容 |
| --- | --- | --- |
| オフィス | `/` | AI社員の在席・状態一覧。タップで詳細パネル |
| 新規依頼 | `/request` | プロジェクト/依頼内容/期限/優先度 →「PMに相談する」 |
| タスクボード | `/board` | 未着手・作業中・レビュー・完了。ボタンで状態変更 |
| AI社員詳細 | `/employees/[id]` | 役割・現在のタスク・作業履歴・得意分野・生成プロンプト |
| 会議室 | `/meeting` | 会議ログ・決定事項・次の担当者 |
| 日報 | `/report` | 本日完了・作業中・エラー・明日の予定・稼働状況 |

## AI社員（初期メンバー）

1. PM「ちゃっぽぬん」 — 依頼整理 / タスク分解 / 割り振り / 最終レビュー
2. UI/UXデザイナー「ぱれっと」 — 画面構成 / デザイン改善 / UX確認
3. エンジニア「こつぶ」 — 実装 / バグ修正 / リファクタリング
4. QAスタッフ「みっけ」 — テスト項目 / スマホ表示確認 / lint・build確認
5. リサーチャー「しらべ」 — 技術調査 / 競合調査 / 最新情報の整理
6. マーケター「ばずり」 — X投稿 / TikTok企画 / 広告文 / 告知

## データ保存

- 保存キー: `niki-office:v1`（バージョン付き）
- 初回起動時のみサンプルデータ（推し活ダッシュボードのプロジェクトと初期タスク）を投入します。
- 既存データは不用意に消しません。保存データが壊れていても削除せず、読み取りエラーとして扱います。

## 退勤演出

- 端末の時刻が **19時** 以降になると、退勤バナーが表示され「全員を退社にする」「全員を残業させる」が使えます。
- 時刻に関係なく試したいときは、オフィス画面右上の **🌙 定時演出** で切り替えられます。

## Vercel へのデプロイ

このアプリはリポジトリ内の `niki-ai-office/` にある独立した Next.js プロジェクトです。
Vercel でプロジェクトを作成する際は **Root Directory を `niki-ai-office`** に設定してください。
